## 🎯 Purpose

The goal of this repository is to document not only the final result of each lab, but also the reasoning and methodology used throughout the process.

Each write-up attempts to answer:
* **What** was discovered?
* **Why** was it interesting?
* **What** vulnerability was identified?
* **How** could it be exploited?
* **Why** did the exploitation work?
* **How** could the vulnerability be mitigated?
* **What** was learned from the lab?
